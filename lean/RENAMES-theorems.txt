# The rule (lean/STYLE.md, "Theorem names"): a theorem name is a snake_case
# sentence that says what is true, with no clipped words. The signs are spelled
#     <=  is_at_most        >=  is_at_least
#     <   is_less_than      >   is_greater_than
#     =   equals            /=  is_not
# The first three were decided by the author on 24 Nov 2026. The other three
# follow the same pattern and have not been confirmed.

# docs/, the README, the paper and the notebooks, and its --check fails if an
# old name is still in use. To change a name later, edit its line here, put the
# name it has now on the left, and run the script.
